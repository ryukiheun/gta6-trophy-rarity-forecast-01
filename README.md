Forecasts each GTA VI PS5 trophy's Exophase earn rate a week after launch. It splits every rate into earners and players tracked and forecasts the two counts separately, so a refresh that jumps the tracked-player count dilutes the rates instead of being extrapolated away — and it widens its logit spread when a refresh is due but unseen.

## Run it

```sh
python3 main.py
```
